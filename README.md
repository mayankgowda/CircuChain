# CircuChain Benchmark

This repository contains the dataset, code, and evaluation logs for **CircuChain**, a diagnostic benchmark designed to evaluate instruction compliance versus physical competence in Large Language Models (LLMs) solving electrical circuit problems.

## 📂 Directory Structure

### `data/`
Contains the core dataset, model outputs, and grading artifacts.

* **`circuchain_full_dataset - final.json`**: The canonical benchmark dataset containing 100 Control/Trap problem pairs with prompts and ground truth values.
* **`graded_master_dataset.json`**: The complete dataset annotated with numerical grading results (Pass/Fail) for every model and subtask.
* **`final_accuracy_table.csv`**: The aggregated results summary used to generate the tables in the paper.
* **`final_diagnosis_gpt5.json`**: The output of the automated Judge (GPT-5) classifying failures into categories (e.g., `ERR_SIGN_CONVENTION`, `ERR_PHYSICS_SETUP`).
* **`solver_model_resposes/`**: Raw text output logs from the models evaluated (GPT-5, Claude Opus 4.5, GPT-4o, etc.).
* **`extracted_values_using_gpt4o/`**: Structured JSON files containing the numeric answers parsed from the raw model responses (used for grading).
* **`spice_verification/`**: Contains the NGSPICE netlists (`.cir` files) and logs used to mathematically verify the ground truth for every problem instance.
* **`spice_logs/`**: Execution logs generated by the SPICE simulator during the ground truth verification process.

### `scripts/`
Contains the Python automation for generating and validating the benchmark.

* **`ngspice_circuit_generator.py`**: A script that procedurally generates SPICE netlists for the 5 supported topologies (Supermesh, Ladder, Bridge, etc.).
* **`verify_and_export_json.py`**: The pipeline script that runs the `.cir` files through NGSPICE, parses the output, and ensures the ground truth values match the analytic solutions.
* **`circuchain_engine.ipynb`**: The main notebook used for data analysis, orchestrating the grading logic, and generating the final statistics.

## 🚀 Usage Note
To verify the ground truth values, ensure you have `ngspice` installed and run the verification script in the `scripts/` directory. The dataset provided in `data/` is already pre-verified.
